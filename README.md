# Wormwhole-website

This repo is a Next.js project using TypeScript and Tailwind CSS. I added a starter page at `pages/index.tsx` and minimal UI component stubs in `components/ui`.

Quick start:
1. Install dependencies: `npm install`
2. Run the dev server: `npm run dev`
3. Open http://localhost:3000

Notes:
- The project uses the `@/*` path alias (configured in `tsconfig.json`). If your tooling doesn't resolve it, use relative imports or update your configuration.
- If you want me to deploy this to Vercel or adjust versions, tell me and I will add configuration or deploy steps.
